# 常驻小窗、置顶与短时免密

## 小窗与置顶

1. 解锁扩展小窗口，点击右上角的图钉，打开**独立常驻小窗**。点击其他网页或应用时，这个小窗不会像工具栏弹窗一样消失。
2. 在常驻小窗中再次点击图钉，进入 **Document Picture-in-Picture 置顶窗口**。浏览器需支持文档画中画；本次已在 Windows Edge 实际验证打开、加载验证码与返回。
3. 置顶窗口内再点图钉，或关闭画中画窗口，即可回到原来的常驻小窗。原小窗在置顶期间显示返回入口，不允许同时操作两份界面。

两步是浏览器约束：工具栏弹窗失焦会被销毁，而画中画随创建它的页面结束；需要先保留稳定的宿主窗口，再由一次用户点击启动画中画。普通 `chrome.windows.create` 没有可写的系统置顶选项，因此不把常驻窗口冒充为始终置顶。

不支持文档画中画的浏览器仍可使用常驻小窗，并会显示明确提示。关闭常驻宿主窗口，也会结束它创建的置顶窗口。macOS 沿用浏览器原生画中画能力，尚未做 Mac 真机验收。

窗口接续使用 10 秒有效、仅能消费一次的内存票据。默认关闭免密时，也可把当前已解锁界面显式交给新小窗，不需要重复输入密码；这不会允许无关页面或随后任意重开的弹窗直接解锁。

## 临时验证码折叠

- 弹窗与常驻/置顶小窗默认只显示一行“临时验证码”。点击后动画展开输入框、当前验证码及倒计时。
- 收起时保留当前窗口中的临时输入，暂停计算并禁止隐藏区域获得焦点；再次展开按当前时间重新计算。
- 锁定或关闭窗口会清除临时输入；重开仍默认收起。独立 `api.html` 页面保持直接输入的布局。
- 尊重系统“减少动态效果”选项，快速连续点击不会留下遮挡层或错误焦点。

## 短时免密

已解锁弹窗点击“打开管理页”时，新管理页可接续本次授权，无需再次输入密码，也不要求开启短时免密。已有管理页优先直接激活，不重新加载，保留搜索和当前解锁状态。若已有页面已锁定，仍显示其锁屏。关闭管理页后从浏览器直接重新打开，仍按短时免密设置判断是否需要密码。

路径：**设置 → 访问门禁 → 短时免密**。

默认关闭。开启时必须确认风险提示；支持 1、5、15 分钟，首次选择默认 5 分钟。延长时长也会再次确认。

- 从最近一次成功输入密码的时间起算；反复重开、仅浏览设置不会无限续期。
- 有效期内重开弹窗、管理页可免输入，并暂缓闲置自动锁定。有效期结束后，重开需要密码；已打开的页面继续按“闲置自动锁定”设置处理。
- 手动锁定立即撤销本浏览器其他窗口的授权，修改密码、清空数据同样失效。
- 关闭免密开关会停止后续免密恢复；当前已解锁页面无需被强制赶出。
- 授权仅保存在 `chrome.storage.session` 内存中，不保存明文密码，不写入 localStorage、持久账号库或云端同步。后台 Service Worker 休眠重启可继续读取有效授权，浏览器会话结束则清除。
- 关闭一个弹窗不等于结束浏览器会话。部分浏览器在关闭全部窗口后仍有后台进程；需要立即结束授权时请使用插件的“立即锁定”。

任何能使用当前浏览器的人，都可能在免密期内查看、复制密码和验证码。管理密码依旧只是界面门禁，不会加密账号库；只建议在可信个人设备上启用。
