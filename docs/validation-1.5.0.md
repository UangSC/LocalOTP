# 1.5.0 验证记录

日期：2026-11-06。环境：Windows、本机 Node 24.16.0、隔离配置的真实 Edge；未访问用户已安装扩展的账号数据。所有密钥和账号均为公开测试数据。

## 交付变化

- 从用户指定的本机 9666 控制台定位到 CPAMP，使用内置浏览器读取其登录页和已加载的完整静态 CSS。未登录业务页面，未读取管理密钥。默认蓝色参考其 `#2563eb` / `#60a5fa`、白色与蓝灰面层、细描边、大圆角卡片及按钮；五套配色与字母头像继续支持。
- 新增弹窗临时验证码与扩展独立 `api.html`；同一输入解析器、同一会话调度、同一界面组件，避免两份算法和交互逐渐不一致。
- 新增 `otp` 地址栏关键字，支持 Base32 / otpauth、算法、位数和自定义周期；参数错误明确失败。
- 移除 Web Crypto 不可用时的伪随机占位码，收紧算法、位数、周期及 Base32 长度/填充校验，修复损坏 URL 标签导致解析异常。
- 修复多账号弹窗行被 flex 压缩导致内容裁切；修复独立长页面下拉菜单因外层自动滚动而立即关闭。

## 布局与性能

- 402×600 弹窗临时组件高 168px，仍有 226px 账号滚动区；账号行完整保留邮箱、密码、验证码按钮，实际滚动到最后一项并复制成功。
- 320 / 402 / 768px 独立页面无横向溢出；宽屏管理页、设置、深浅主题均做截图检查。
- 五套深浅主题的设置说明、主按钮和强调文字对比度均 ≥4.5:1。头像三档渐变最低 **5.46:1**。
- 临时会话同周期只更新秒数，跨周期才计算 HMAC；复制时另行重算。页面隐藏后没有调度定时器，恢复后按绝对时间计算。旧输入的异步结果不能覆盖新输入，清除后不能被在途计算重新填回。
- 500 条账号重复渲染复用了全部节点；本轮测试耗时约 **89ms**，仅为渲染函数耗时，不代表首次加载和全部 HMAC 耗时。
- `gate-motion.js` 和 `list.js` 与本次修改前 SHA-256 完全一致，现有动画时间线、错峰、悬停及复制反馈保留。CSS 只调整视觉属性和弹窗行的收缩规则。

`node tools/perf.mjs --details`（1280×820、GPU 无头 Edge）实测：纯色动画基线 **46 FPS**；首次展开 **44 FPS**、最差 **83.3ms**。连续三轮锁屏/解锁分别 **57/60、60/60、60/58 FPS**；锁屏完整流程约 **703–722ms**，解锁包含密码校验与准备约 **948–981ms**。热过程最差帧 17–50ms。结果受本机负载及调度影响，不承诺所有设备固定 60 FPS。

## 验证边界

- 已验证 Windows Edge 的真实扩展；MacIntel 平台提示与 Command K 通过模拟验证。未在 macOS 真机、Chrome 实机或 Safari 上运行，不把这些视为实机通过。
- 真实扩展已注册 `otp` 关键字，三种打开方式的监听器经过隔离模型测试，URL 最终页面经过实际扩展测试。没有自动操作原生地址栏完成一次端到端关键字输入。
- 同步测试未登录云端浏览器账号，未验证 Windows/Mac 两台设备云端传输。既有账号库与同步仍未做端到端加密；临时验证码不进入这些存储。
-  URL 参数移除不能保证擦除浏览器此前记录的地址栏输入。
