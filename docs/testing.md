# 测试与验证

`npm test` 是统一入口，按顺序运行核心逻辑、门禁和真实浏览器用例，遇到失败立即退出。测试使用隔离浏览器配置，不读取日常个人资料。需要可启动的 Edge / Chromium；可在 `tools/cdp.mjs` 的候选路径中添加本机浏览器。

浏览器驱动随机选择调试端口；Windows Edge 启动传入 `--edge-skip-compat-layer-relaunch`，避免兼容层重启后启动器先退出、实际浏览器残留并污染下次测试。

## 当前正式版本的验证重点

- 模块拆分保持原来的数据格式、DOM 结构及加载顺序。
- 不开启短时免密也能从已解锁弹窗进入新管理页；已存在的管理页不重载，已锁定页面不被跳过。
- 真实存储往返后的字段重排不会造成无修改的重复读取/写入。
- 新演示账号、密码、密钥和导入文件都是此次生成的公开测试夹具。
- 固定扩展 ID 保持不变，不新增持久站点、`tabs` 或管理其他扩展的权限。

当前正式配置保留开发迭代中引入的 `activeTab` 和 `scripting`，用于用户在目标页打开扩展后的单次截图。自动化的 `chrome.action.openPopup()` 不会模拟用户点击授予 activeTab；截图集成用例在隔离扩展副本中添加 `<all_urls>` 以调用真实截图 API，源码与发布包没有该权限。此用例不能代替真实工具栏点击授权和各类受保护网页的人工检查。

截图集成用例通过实际扫码按钮进入流程，验证工具栏弹窗、常驻小窗和真实 Document PiP：切换当前网页后在该网页出现蒙版，插件小窗内不调用来源选择器、不展示网页缩略画面；同时检查真实工具栏文档高度不超过可视区域。布局回归另行覆盖缩放和导入/设置切换后的分段滑块测量。

## 云端传输边界

隔离用例显式关闭云同步或没有登录账号，只能验证缓存与本地行为。内存模拟的数据传递不是微软或 Google 同步服务验收。

用户反馈旧 ID 迁移后 Windows / macOS Edge 已能收到账号。进一步验收应只在 A 导入带唯一标记的测试记录，确认 B 自动出现；随后由 B 修改备注、由 A 确认，再测试删除与离线重连。两个设备各自导入相同数据不构成云端同步证据。

`ui-polish-test.mjs` 覆盖光标、圆环字号、清晰动画、680px 布局和限高适配，并使用公开二维码画布产生真实 MediaStream 驱动画面读取，验证截图后轨道停止、取消重试和当前页解析。该用例替代了来源选择器的人工选择，不宣称验证系统原生选择器界面。五套配色的深浅模式检查切换瞬间输入、占位及禁用文字对比度。

帧率探针把密码校验、样式提交和绘制都计入完整操作窗口，不能把首次绘制长帧直接当作动画本体的 FPS。管理页首次和后续均播放展开/收回动画；用 `node tools/perf.mjs --headed --details` 补充桌面 Edge 采样，冷启动与连续往返分别报告。实机体验仍受浏览器、显示刷新率和设备负载影响。
