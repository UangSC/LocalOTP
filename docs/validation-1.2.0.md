## 动效测量

`node tools/perf.mjs --details` 使用 1280×820、启用 GPU 的无头 Edge。以同进程的纯色块动画作为环境基线。

- 修改前一次测量：基线 60 FPS；展开约 47 FPS，最差帧 116.7ms。
- 修改后一次测量：基线 60 FPS；展开约 60 FPS，最差帧 17.4ms。连续三轮锁屏和解锁均约 60 FPS，最差帧约 17ms。
- 最后复测：展开约 57 FPS，最差帧 50ms；三次解锁均约 60 FPS；三次锁屏约 60 / 48 / 60 FPS，其中第二次有约 117ms 的单帧波动。
- 热解锁完整流程（包含密码校验和绘制准备）约 812–836ms；锁屏约 495–515ms。展开阶段不是总响应耗时。

已移除重复入场和全屏白色收尾，预先完成内容绘制并统一清理动画。测量仍会受到机器负载、浏览器调度、验证码换周期等影响，不保证任何设备固定 60 FPS。

## 同步验证边界

真实扩展测试使用未登录账号的隔离浏览器，验证了本机同步存储 API、后台任务、变更监听和重开弹窗。没有验证两台已登录同一浏览器账号的设备之间的云端传输。

浏览器同步需要相同浏览器账号、已开启相关同步设置和相同扩展 ID。解压加载的 ID 可能因路径或配置不同而改变。当前版本保留已有 ID 配置，没有新增 manifest key 来强行改变用户现有安装身份。

同步内容未做端到端加密；管理密码只用于界面门禁。设置页和 README 均明确说明。
