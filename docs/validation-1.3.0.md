# 1.3.0 动效与视觉修订

验证日期：2026-10-29。Windows 本机，独立 Edge 测试配置，使用虚构演示账号；没有访问或修改用户实际扩展中的密码与账号。

## 本次修正

1. **锁屏闪动根因**：1.2.0 结束时恢复了 `.lock-card` 的 CSS `animation`，登录卡因此再次从透明状态入场。现在收尾保持 `animation: none`，在撤销 WAAPI 前提交静态终态。
2. **形变不明显的根因**：1.2.0 壳体提前淡出，只剩整页渐变。本版壳体全程不透明，保持 680ms 的完整展开／收缩轨迹；页面同步裁切，逐层呈现内容。
3. **列表动效**：恢复可见条目的错峰上浮、轻微越过终点再回正；视图和分类切换包含旧内容退场与新内容位置过渡。快速连点会取消旧动画与快照；最多 24 个可见项参与，普通同步仍复用节点。
4. **材质**：参考 `2FA_2` 的浮层、聚光与反馈语言，保留本项目紫色主题，增强细边高光、层次投影、悬停光晕和按压反馈。管理页卡片增加留白和底部操作区，深色另调文字与高光。
5. **头像**：仅拉丁字母。服务名 → 邮箱 → 域名 → AC，不再放图标或汉字；恢复悬停轻转和复制弹跳。
6. **刷新旋转**：独立播放 620ms；本地计算很快完成时，旋转不会被忙碌状态清理一起取消。

## 性能边界

本版以保留完整形变和细节为目标，没有把丰富动效重新降级为单纯淡出。

启用 GPU 的无头 Edge、1280×820，纯色块基线约 60 FPS。一次测量中首次展开约 49 FPS / 最差 83.3ms，连续三轮解锁约 60 / 54 / 60 FPS，锁屏约 56 / 60 / 60 FPS。最终扩大采样窗口、去掉超长帧过滤后，首次展开约 42 FPS / 最差 116.6ms。

首次解锁仍存在图层与字体首次绘制峰值，不能据此宣称所有情况下固定 60 FPS。准备阶段会等待连续稳定帧，有 600ms 上限；完整解锁包含密码校验、预绘制和形变，不能只拿动画阶段时长作为总响应时间。

500 条账号重复渲染保持节点复用；一次回归中渲染函数约 47ms，首次建库与全部验证码计算不包含在这个数字中。
