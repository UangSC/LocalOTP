# 1.4.0 设置文字与五套色系

日期：2026-10-29。测试使用隔离 Edge 和虚构演示数据。

## 交付内容

- 设置页标题颜色修正，说明文字加深；标题 500、说明 400 字重，按钮与选项以常规字重为主。
- 主题下方新增五个色系单选项：经典紫、清新绿、天空蓝、少女粉、黑白。
- 五套色系分别定义浅深色画布、面层、搜索背景、品牌色、按钮前景、边框和环境光。黑白方案浅色用黑主按钮、深色用白主按钮，头像为灰阶。
- 页面、弹窗、锁屏、菜单沿用同一套色系；管理页与弹窗共享本机偏好，重载前同步读取主题镜像。
- 色系与明暗主题独立，跟随系统不改变已选色系。方向键、Home/End、单选状态、快速连续切换均覆盖。
- 设置内配色切换直接预览，避免整页 View Transition 快照挡住后续点击；普通主题过渡保留，旧任务不会覆盖最后选择。
