# 1.6.0 验证记录

日期：2026-11-06。Windows 本机、隔离 Edge 配置、公开测试账号。没有更改用户已安装扩展的密码、同步或免密偏好。

## 实现与验证

- 右上角图钉先打开唯一的常驻小窗，再次点击可打开浏览器原生 Document PiP。真实 Edge 已验证票据交接、无需重复密码、窗口复用、PiP 内验证码计算、返回原窗口及跨窗口锁定。
- 默认临时验证栏为 **44px**。展开有高度过渡；收起暂停计时、保留本窗口输入并移除隐藏焦点。快速点击、重新展开计算、锁定清除通过。
- 短时免密默认关闭，支持 1/5/15 分钟。真实风险弹窗的取消和确认均验证；确认后会话存储签发固定期限，重开不续期。实际越过闲置阈值仍保持免密，到期重开需要密码。
- 会话操作在后台串行执行。密码版本变化、时钟回拨、手动锁定、关闭偏好、伪造证明、重复票据、后台重启等由核心测试覆盖。实际改密也验证了锁定、租约撤销与旧密码拒绝。
- 账号库没有新增密码保存逻辑；会话证明和票据只在 `chrome.storage.session`，不写入同步存储。签发须先真实验证密码，页面不能用一个布尔值伪造验证成功。
- 设置增加同步操作说明和扩展 ID；原同步传输模型保持不变。

## 边界

- 系统置顶由 Document PiP 提供。不能把普通常驻窗口当成 always-on-top；工具栏弹窗与画中画要求两个用户点击，原因见使用说明。
- 已在 Windows Edge 的真实扩展中验证 Document PiP API、内部页面和验证码；未另行做外部应用遮挡的系统 Z 序自动化测试，未在 macOS 真机验收。
- 核心测试验证了后台重启与浏览器会话清空后的恢复判定；本轮未重启用户的日常浏览器。`storage.session` 的生命周期由浏览器管理。
- 同步不是模拟接口，但未完成两台已登录浏览器的云端链路验收。管理密码仍是界面门禁，账号库没有额外端到端加密。
