# 样式与交互约定

页面共享六套双色渐变主题（浅色 3 组：ocean 晨曦蓝青、aurora 极光紫樱、sunset 暖阳珊瑚；深色 3 组：midnight 深海极光、nebula 星云暮紫、ember 暮焰流金）并支持跟随系统自动配对明暗。修改颜色优先调整令牌，不在业务脚本里硬编码背景或文字颜色。

## 样式分层

| 文件 | 职责 |
| --- | --- |
| `tokens.css` | 间距、字号、圆角、阴影、基础颜色 |
| `base.css` | 通用布局、可访问性基础与滚动行为 |
| `components.css` | 账号列表、按钮、输入等组件 |
| `overlays.css` | 抽屉、对话框、表单、提示及弹出菜单 |
| `page.css` | 管理页布局 |
| `finish.css`、`studio.css` | 共享视觉细节与页面一致性调整 |
| `color-schemes.css` | 六套双色渐变主题（明暗各 3 组）及语义令牌 |
| `otp-tools.css`、`window-tools.css` | 临时验证码、常驻窗口和免密控件 |

HTML 的样式顺序是层叠规则的一部分。合并或移动规则前，检查三个页面的深浅色、弹窗宽度与设置抽屉；不要仅凭某个页面正常就删除后置覆盖。

## 组件与文案

- 弹窗固定使用紧凑账号行，管理页支持列表和卡片。
- 密码隐藏、锁屏仅防止随手查看，不代表加密；风险告知保持准确。
- 未设置分类的账号头像使用字母和主题颜色，已设置分类的账号头像直接使用对应分类的 SVG 图标；不请求远程头像。
- 所有操作有明确的可点击状态、焦点样式和可访问名称；选中状态同时使用形状或标记，不能只依赖颜色。
- 正文、说明文字保持足够对比度；失败、警告、成功使用对应语义色。
- 不把私密数据写入持久日志，也不为临时 OTP 输入增加后台保存。
- 字符头像悬停保持原尺寸，不旋转或缩放。管理页卡片悬停只将验证码字号从 27px 改为 28px，不增加验证码小边框；账号与服务名保持清晰间距。
- 管理页列表与卡片的验证码均不增加悬停描边、背景框或外扩阴影。导航滚动区保留位移、焦点环和阴影所需的留白，只允许纵向滚动；长导航条目不能被 flex 压缩。
- `scan.css` 使用现有主题令牌，负责扫码预览、截图框选、密码验证弹窗和访问设置。

## 动画与性能

门禁动画由 `js/gate-motion.js` 控制，列表切换由 `js/list/motion.js` 控制。文字内容使用短淡入淡出与裁切，避免缩放、模糊滤镜、整页截图过渡和持续 will-change；空白背景与装饰层可独立形变。

尊重减少动态效果偏好。页面隐藏时暂停不必要的验证码计算；列表更新复用已有元素，倒计时按需更新文本和环形进度。折叠的临时验证码组件停止计算，重新展开使用当前时间。

验证方法见 [测试说明](testing.md)。截图只作为本地检查材料，放入忽略的 `artifacts/`。

表单的普通、聚焦、占位和禁用状态均使用主题语义色；输入文字和占位文字对比度至少 4.5:1。切换配色时先关闭颜色补间，再一次提交整套颜色，防止浅底浅字。普通展示区用箭头，按钮用手形，只有可编辑文本框显示 I 形光标。弹窗倒计时数字至少 13px，管理页卡片至少 14px。

管理页首次与后续解锁均从登录卡展开为管理面板，锁定时沿相反路径收回。空白背景独立形变，真实内容保持原始尺寸并同步裁切、淡入淡出，不能用整页硬切代替原动画。首次完整绘制在登录卡后的临时遮罩下进行，后续往返只提交初始帧；结束或中断后移除临时层和 will-change。锁定开始立即禁止账号区交互，减少动态效果偏好及窗口变化保留稳定终态。
