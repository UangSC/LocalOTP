# 视觉与交互规范

这份文档只讲"为什么长这样"，以及改界面前需要知道的约束。
令牌与组件分层：基础值在 `tokens.css`，色系在 `color-schemes.css`，1.5.0 的 CPAMP 视觉统一在 `studio.css`，临时验证码组件在 `otp-tools.css`。


## 1.5.0 当前设计

参考 CPAMP 已加载的静态样式：浅色实心按钮 `#2563eb`，强调色 `#3b82f6`；深色按钮 `#60a5fa`，卡片 `#1b1f2a`。白色/蓝灰卡片、20px 大圆角、12px 按钮、细描边和轻阴影构成主要层次。为保证可读性，弱文本比参考面板加深，深色主按钮采用深墨色前景。

五套色系均保留。默认天空蓝，已有选择不被覆盖。头像只使用字母与主题令牌；全局文字保持常规字重，标题有层级，设置说明不加粗。代码块与错误信息采用次级面层、等宽文本及语义色；不为两步验证码工具添加无意义的持久日志或记录临时密钥。

`studio.css` 不重定义任何关键帧或动画时长；`gate-motion.js`、`list.js` 保持原样。新组件只更新秒数与环形进度，页面隐藏时暂停计算。弹窗 `.quick` 禁止 flex 收缩，以实际内容高度滚动。

独立页面和弹窗共用临时组件，账号库与临时输入的生命周期分别管理。URL 页面不加载 store，不保存临时密钥；高级参数使用既有自定义下拉菜单，otpauth 参数回填后禁用覆盖。

以下章节保留早期设计的来源和演进记录；发生差异时以本节及当前样式为准。

## 1. 合并的判断

两个原型各自是自洽的，但目标不同：

- `2FA` 关心**可读性**：浅底、白卡片、克制的阴影，一眼扫完 12 个账号。
- `2FA_2` 关心**手感**：近黑底、发光、按钮的即时回执，操作像在摸一个实体。

合并版选择了 2FA 的"底"和 2FA_2 的"手"：

> **静态时像 2FA，被操作时像 2FA_2。**

具体做法是让"光"变成**状态的函数**而不是装饰：

| 状态 | 光 |
| --- | --- |
| 静置 | 只有 1px 描边 + `0 1px 2px` 的阴影 |
| 悬停 | 上浮 1px，阴影到 `--shadow-m`，**不换底色** |
| 搜索命中 | 品牌色描边 + 左侧光条 + 22px 半径的外发光 |
| 复制成功 | 整块泛光一次（620ms），然后**完全退干净** |
| 快没时间 | 倒计时环转琥珀，最后 4.5 秒转玫红并开始呼吸 |

## 2. 色彩

1.4.0 起色系与明暗主题分离：`data-color-scheme` 为 purple / green / blue / pink / mono，
`data-theme` 为 light / dark（auto 由系统解析）。`color-schemes.css` 在其他样式之后定义对应令牌。
下面的紫色数值是最初设计基准；当前生效值以色系文件为准。

五套均覆盖画布、面层、搜索背景、品牌色、按钮前景、聚光、描边、锁屏和环境光。
黑白色系的浅色按钮用黑底白字，深色按钮用白底黑字；头像灰阶。错误/告警/成功仍保留语义色。

设置正文使用明确深色（深色主题为浅亮字），标题 500、说明 400，不能把标题内部 span 统一染成说明色。
色系选择位于主题下一行，五枚 radio 按钮支持方向键，选中同时有边框和勾选提示。


### 2.1 品牌

```
#5B5BF0 ── #8B5CF6     浅色主色（深色提亮到 #8C8CFF / #B18CFF）
```

渐变只出现在三个地方：品牌标识、主按钮、实时预览块。
除此之外**任何大面积都不用渐变**——这是 2FA 的克制，也是它看起来"贵"的原因。

### 2.2 面层

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#F4F5FA` | `#0C0E15` | 主屏底色 |
| `--surface` | `#FFFFFF` | `#161A25` | 卡片、抽屉 |
| `--surface-2` | `#FAFBFF` | `#1A1F2C` | 卡片内部的次级块（设置分组） |
| `--search-bg` | `#EDEFF7` | `#1C212E` | 搜索框静置底色 |
| `--line` | `#EAECF4` | `#242A39` | 常态描边 |
| `--line-strong` | `#DEE1ED` | `#2E3547` | 输入框、需要"边界感"的地方 |

深色下**内层比外层亮**（surface 比 bg 亮），靠明度差而不是描边分层；
浅色下相反，靠阴影和描边分层。

### 2.3 文字

`--ink` → `--ink-2` → `--ink-3` → `--ink-4` 四级。
正文一律 `--ink`，说明文字 `--ink-3`，**`--ink-4` 只用于非关键辅助**
（例如"点击行复制验证码"这类提示），因为它对比较低。

### 2.4 语义色

成功 `#0FAE7E`、警示 `#F59E0B`、危险 `#F0483E`，
各自带 `-soft`（底纹）与 `-ink`（在浅底上的可读前景）。
**语义色只用在语义上**：倒计时告警、无效导入行、删除确认。
头像配色是身份色，不承担语义——所以它用另外一套（见 §5）。

### 3.1 字号（402px 弹窗下的精密刻度）

```

```

4 的倍数；行内元素用 5–10，区块之间 12–16。

## 4. 动效

### 4.1 三条曲线

```css
--e-out:    cubic-bezier(.22, 1, .36, 1);   /* 入场、抽屉、面板 */
--e-spring: cubic-bezier(.34, 1.32, .64, 1);/* 按压、滑块、Toast */
--e-inout:  cubic-bezier(.65, 0, .35, 1);   /* 呼吸、漂移等循环 */
```

`--e-out` 是主力：起手快、尾巴极慢。观感上"贵"的界面基本都是这条曲线。

### 4.2 时长

```
110ms  按压、hover 变色
180ms  气泡、次级状态
280ms  卡片位移、图标切换
420ms  抽屉、锁屏、入场
660ms  复制回执、主题切换
```

### 4.3 动效清单

| 触发 | 表现 | 时长 / 曲线 |
| --- | --- | --- |
| 列表首次渲染 | 逐条上浮入场，前 16 条错峰 26ms | 420 / `e-out` |
| 周期边界换码 | 下落 5px + 模糊 2px + 回正 | 380 / `e-out` |
| 复制验证码 | 整行泛光（`::after`）+ 验证码上跳 1.5px + 波纹 | 620 / 420 / 640 |
| 复制邮箱 / 密码 | 图标换勾 + 品牌色底 + 气泡变「已复制」 | 760 后还原 |
| 搜索命中 | 描边浮现 + 左侧光条淡入 + `<mark>` 荧光笔 | 280 |
| 解锁 / 锁屏 | 预绘制内容，环境背景遮罩与卡片同步过渡，无全屏白色收尾 | 480 / `e-out` |
| 密码错误 | 输入框横向抖动（-6 → 5 → -4 → 3 → -1.5） | 440 |
| 抽屉打开 | 从下往上滑入（宽屏从右），遮罩 2px 模糊 | 420 |
| 主题切换 | View Transitions 整页交叉淡入 | 系统默认 |
| 倒计时告警 | ≤10s 转琥珀；≤4.5s 转玫红 + 呼吸缩放 1.045 | 1150 循环 |

**所有动效在 `prefers-reduced-motion: reduce` 下关闭**（时长压到 0.01ms）。

### 4.4 性能约束

- 倒计时按墙钟整秒统一更新，CSS 在两秒值之间补间；锁屏或切到后台停止调度。
- 按 ID 与内容复用列表节点；没有变更时不重建 DOM。
- 大页面本身不参与缩放；图层绘制在形变开始前准备，动效仅处理小卡、环境遮罩与形变背景。
- `paint()` 只有数值真的变了才写 DOM。
- 复制回执画在覆盖层上，只动 `opacity/transform`——**不去改元素自身的底色与描边**，
  否则动画结束后外观回不到常态（这是 2FA_2 踩过的坑，注释保留在 CSS 里）。

## 5. 随主题变化的字母头像

1.4.1 起不再保存固定多色调色板。服务名称哈希只决定 `data-avatar-tone` 的三个轻重档位。
`--avatar-fill-start` / `--avatar-fill-end` / `--avatar-text` / `--avatar-stroke` 从当前色系角色派生，
五种色系 × 浅深主题分别更新。浅色为柔和浅底配深字，深色为低亮度底配亮字，黑白保持灰阶。

材质保留顶部轻高光与小范围投影，避免厚重凸起；字母独立置于上层，字重 650。
悬停上移、轻微旋转与复制回弹保留。语义告警色不作为头像随机配色。

参考 Radix Avatar 的 soft / highContrast、Radix Colors 的背景与文字色阶角色、
Atlassian 的主题色彩令牌。具体来源和对比度检查见 `validation-1.4.1.md`。

## 6. 组件规格

### 6.0 小窗的快速复制行

小窗只做一件事，所以它的行是**为复制键让路**的：

```
[26 头像] 邮箱 13/620                 ⚲ [26 环]
          服务名 10.5 灰
[ ✉ 邮箱 ] [ 🔑 密码 ] [ 966 682       ⧉ ]   ← 27 高，等距 6
```

（图钉 `⚲` 只在悬停 / 聚焦 / 已锁定时出现，是"聚焦锁定"的入口。）

| 项 | 值 | 理由 |
| --- | --- | --- |
| 卡片内边距 | 8 / 10 | 比大页面的行更紧，一屏能多放半行 |
| 键高 | 27 | 鼠标点击的舒适下限（配合 10px 内边距，命中区约 47×27） |
| 邮箱 / 密码键 | 中性底 `--surface-3`，13px 图标 + 11px 文字 | 有文字才不用猜；不抢验证码的戏 |
| 验证码键 | `flex:1`，浅品牌底 + 1px 品牌边，14.5px 等宽 | 一行里最常用的是它，给最大面积与最高对比 |
| 复制成功 | 键变为 `✓ 已复制`，760ms 后还原；**不弹 Toast** | 就地反馈已经足够，弹窗里每多一条浮层都在挡列表 |
| 点卡片空白 | 复制验证码 + 波纹 + 整行泛光 + 带码 Toast | 这条保留全局 Toast：要让你看清复制的是哪串数字 |

验证码键里**没有**单独的"已复制"文案，只换图标——因为数字本身要留在原位继续倒计时。

### 6.1 大页面的列表行

```
[34 头像] [邮箱 14/600 │ 服务名 + 复制按钮 + 更新于] [验证码 16 等宽] [34 环] [⋯]
```

- 高 58，内边距 10/14，列间距 24
- 邮箱与服务名是 1.1fr / 0.9fr 两列网格，服务名贴列首
- 复制按钮（邮件 / 钥匙，19px）在服务名之后、"更新于"之前
- `⋯` 只在悬停 / 聚焦 / 选中时出现，作为右键菜单之外的发现路径
- 列标题（邮箱 / 服务 / 验证码）与行**共用同一套栅格**，左右内边距按
  `列表 22 + 行 14` 复用，所以左右边缘能对齐

### 6.2 大页面的卡片

```
[22 头像][服务名 10.5 灰][26 环]
邮箱 12.5/600
验证码 16 等宽            （右下角：邮件 / 钥匙 21px）
```

- 最小高 104，宽屏 `repeat(auto-fill, minmax(236px, 1fr))`
- 每个子元素 `flex: 0 0 auto`——曾经因为允许收缩，邮箱那一行被压成 0 高
- 卡片视图下自动隐藏行列表头

### 6.3 倒计时环

三层同心圆（`pathLength=100`）：

| 层 | 线宽 | 说明 |
| --- | --- | --- |
| 轨道 | 2.6 | `--ring-track` |
| 光晕 | 7 | 只在 warn/hot 时 `opacity: .3` |
| 进度 | 2.6 | `currentColor`，圆头 |

状态机：`calm`（品牌紫）→ `warn`（≤10s，琥珀）→ `hot`（≤4s，玫红 + 呼吸）。

**弧长与数字同源**（这是"进度条不同步"的根因修复）：

| 项 | 规则 |
| --- | --- |
| 数字 | `Math.ceil(remaining)`，即显示的整数秒 |
| 弧长 | `100 - (显示的秒数 / 周期) × 100` —— 直接由上面的整数算，不另取小数进度 |
| 更新频率 | 每秒一次，**同一个 `Date.now()`** 喂给所有环 |
| 过渡 | `stroke-dashoffset 1000ms linear` —— 两次写值之间由 CSS 补间，画面连续 |
| 跨周期 | 加 `.is-snap` 一帧禁用过渡，瞬切回满格（否则会反向扫一圈） |
| 呼吸相位 | `--pulse-delay` 由墙钟推出来，重渲染后所有环仍同相位 |

这样数字与弧永远自洽；同周期的账号在任何一帧都完全一致。
数字在环心，`tabular-nums`，状态变化时颜色一起过渡。

### 6.4 迷你按钮

```
19×19（卡片 21×21）圆角 5
默认：--ink-3 @ 72%，悬停整行才到 100%
hover：品牌色 + 品牌底纹
active：scale(.82)
成功：图标换成勾 + 品牌底 + 气泡文案换成「已复制」，760ms 后还原
```

### 6.5 分段控件

滑块位置**按真实按钮宽度测量**（`offsetWidth` / `offsetLeft`），
所以「跟随系统 / 浅色 / 深色」这种长短不一的按钮也能严丝合缝。

- 浅色：轨道 `#F2F3F9`，滑块纯白
- 深色：轨道 `rgba(255,255,255,.045)`，滑块 `rgba(255,255,255,.13)`
  ——深色下滑块**必须比轨道亮**，否则看起来像被按下去

### 6.6 抽屉

- 弹窗：从底部滑入，最大高度 `100% - 22px`，顶部圆角 20，抓手 34×4
- 宽屏：从右侧滑入，宽 480，左侧圆角
- 内容区滚动、页脚固定；关闭后延时 440ms 再清空内容，避免"闪空"

### 6.7 焦点状态（只有一层）

焦点被拆成两种，规则写死在 `base.css`：

| 对象 | 表现 |
| --- | --- |
| 输入框（`input/textarea/select`） | **不画 outline**。由外层容器画「1px 品牌边 + 3~4px 柔光」 |
| 带柔光的容器（`.search` `.pw-wrap` `.field-input` `.imp-input`） | 同上，自身不再补一圈 |
| 抽屉 / 对话框（程序化聚焦，仅为键盘滚动） | 不画任何焦点框 |
| 按钮 / 链接 / 可聚焦行 | 键盘 `Tab` 到时画 2px 品牌描边、偏移 2px；鼠标点击不留框 |

> 这条规则是"两层框"的根因修复：之前输入框既被容器画了边，又在
> `:focus-visible` 上画了自己的外框，两圈套在一起。现在任何元素、任何时刻
> 最多只有一层焦点提示。

### 6.8 管理页的登录卡与展开动画

弹窗里的锁屏是**铺满**的（402×600 本来就小，不需要再套卡片）；
管理页里换成一张 **362px 居中卡片**。锁屏时页面骨架（侧栏、表头、列表）
**完全不出现**——不是把它压暗，而是 `opacity: 0` + `.page` 去掉底色和投影，
所以背景里不会出现"提前摆好的一块面板"。

```
            ┌──────────────────┐
            │   ● 品牌徽标      │
            │   LocalOTP        │  362px 宽，圆角 20，阴影 --shadow-l
            │   输入管理密码     │
            │   [ 解锁 ]        │
            │   快捷键 · 清空    │
            └──────────────────┘
        背景：body 的环境光（无毛玻璃、无面板）
```

门禁由 `gate-motion.js` 管理 680ms 的完整形变：壳体始终保持可见，矩形从登录卡走到页面边界，
真实内容按相同缓动同步裁切。背景壳和页面内容分层，列表和侧栏按节奏显现。
面板到达最大尺寸时，真实内容已经进入，不会留下全屏纯白收尾。

解锁将准备和运动分开：在登录卡下预绘制动画图层，暂停在可绘制状态，等连续稳定帧后从起点统一启动。
准备有 600ms 上限，不阻塞后台恢复。锁屏后段让登录卡从下方 12px / .94 比例回到终态，
动画结束后保留 `animation: none`，不恢复初次入场 CSS，避免第二次透明入场造成闪动。

约束：

- 形变面板和登录卡在 body 中定位，实际内容由 stage 层叠顺序配合。
- 内容不进行大幅缩放，以裁切保留文字清晰度；圆角随壳体几何变化保持连续。
- 锁屏立即禁用内容和侧栏、取消视图切换动画并清除旧快照与通知。
- 收尾处理完成、隐藏、窗口调整和减少动态效果模式，保证无残留覆盖层。
- 不能为了性能指标再次把完整形变替换成全屏淡出；帧率与首绘边界据实记录。

### 6.9 视图滑动开关

工具栏右上是 `ui.swipeSwitch()`：一条胶囊轨道，左列表、右卡片，滑块停在当前侧。

```
( ● ) [≡] [▦]      ← 滑块在左 = 列表
      [≡] [▦] ( ● ) ← 滑块在右 = 卡片
```

- 两个按钮放在 `role="group"` 中，分别用 `aria-pressed` 表达选中状态；点击对应视图，再点已选项保持不变。
- `←` / `→` 选择并聚焦对应按钮，空格 / 回车使用原生按钮行为。
- 滑块不接收指针事件；切换先提交状态，再对旧可见项快照播放 180ms 退场，对新条目播放 520ms 的对应位置过渡与错峰入场。快速连点取消旧任务，以最后选择为准。

### 6.10 内容复用

账号 ID、布局与内容未变化时复用原 DOM；修改一条记录只替换相应节点。
设置变化、分类计数和后台同步不再触发整页错峰动画。

### 6.11 工具栏的刷新按钮

滑动开关右侧一颗 34px 的圆形箭头按钮：

| 行为 | 细节 |
| --- | --- |
| 点击 | 重算全部验证码与进度环（`list.refreshAll()`）；然后按开关状态调用 `store.sync.now()` |
| 反馈 | 图标 `lotp-spin` 转 620ms，同时按钮换品牌色底（`is-busy`） |
| 回执 | 完成后一条 Toast「验证码已刷新」 |
| 防抖 | `runtime.refreshing` 闸门，重复点击直接忽略 |

旋转使用独立的 WAAPI transform 动画；取消上一轮图标动画后重播，不强制回流，不依赖同步任务耗时。

## 7. 已知取舍

| 取舍 | 原因 |
| --- | --- |
| 搜索时不过滤，只打光 | 保留空间关系，用户知道"命中的那条在整列里的哪儿" |
| 单击复制、双击编辑 | 单击必须有即时手感，不能等；双击是补充路径 |
| 小窗只留三枚复制键 | 分类、排序、视图切换都是"管理动作"，挤进 402px 只会让复制变慢 |
| 快速添加容忍 `--` | 手打时 `----` 太费劲；代价是密码里含 `--` 时必须改回 `----`，界面里写明了这句 |
| 聚焦锁定压到 14% | 比搜索的 28% 更狠：锁定只有一个目的——让你只看见这一条 |
| 展开动画只动一个合成层 | 视觉上"内容从面板里长出来"，实现上只缩放一块空面板，不重光栅内容 |
| 关着的抽屉必须 `visibility: hidden` | 只靠 `transform` 挪到屏幕外的话，它的 `box-shadow` 仍会渗回页面——宽屏右侧那道"边框阴影"就是它 |
| 弧长只认整数秒 | 放弃了亚秒级精度，换来"数字与弧绝对自洽"——反正 0.3 秒的差异本来也看不出来 |
| 视图切换只做点击，不做手势拖动 | 桌面端鼠标拖动容易误触，还会抢走"拖选文本"；滑动感交给两段式过渡去做 |
| 拷贝邮箱 / 密码不弹 Toast | 按钮就地变「已复制」已经说清楚了，浮层会挡住半屏列表 |
| 卡片不显示备注 | 402px 内塞不下第四行信息，备注在编辑抽屉里 |
| 导入文本框关闭连字 | 等宽字体会把 `----` 合成一条破折号，用户就看不见真正的分隔符 |
| 主题值镜像到 localStorage | `chrome.storage` 是异步的，不镜像就会白闪一帧 |
