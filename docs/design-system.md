# 样式与交互约定

页面共享五套色系（blue、purple、green、pink、mono）和 light / dark 主题。修改颜色优先调整令牌，不在业务脚本里硬编码背景或文字颜色。

## 样式分层

| 文件 | 职责 |
| --- | --- |
| `tokens.css` | 间距、字号、圆角、阴影、基础颜色 |
| `base.css` | 通用布局、可访问性基础与滚动行为 |
| `components.css` | 账号列表、按钮、输入等组件 |
| `overlays.css` | 抽屉、对话框、表单、提示及弹出菜单 |
| `page.css` | 管理页布局 |
| `finish.css`、`studio.css` | 共享视觉细节与页面一致性调整 |
| `color-schemes.css` | 五套色系及深浅色语义令牌 |
| `otp-tools.css`、`window-tools.css` | 临时验证码、常驻窗口和免密控件 |

HTML 的样式顺序是层叠规则的一部分。合并或移动规则前，检查三个页面的深浅色、弹窗宽度与设置抽屉；不要仅凭某个页面正常就删除后置覆盖。

## 组件与文案

- 弹窗固定使用紧凑账号行，管理页支持列表和卡片。
- 密码隐藏、锁屏仅防止随手查看，不代表加密；风险告知保持准确。
- 账号头像使用字母和主题颜色，不请求远程头像。
- 所有操作有明确的可点击状态、焦点样式和可访问名称；选中状态同时使用形状或标记，不能只依赖颜色。
- 正文、说明文字保持足够对比度；失败、警告、成功使用对应语义色。
- 不把私密数据写入持久日志，也不为临时 OTP 输入增加后台保存。

## 动画与性能

门禁动画由 `js/gate-motion.js` 控制，列表切换由 `js/list/motion.js` 控制。沿用现有运动参数；不要在纯配色修改中改动时长和关键帧。

尊重减少动态效果偏好。页面隐藏时暂停不必要的验证码计算；列表更新复用已有元素，倒计时按需更新文本和环形进度。折叠的临时验证码组件停止计算，重新展开使用当前时间。

验证方法见 [测试说明](testing.md)。截图只作为本地检查材料，放入忽略的 `artifacts/`。
