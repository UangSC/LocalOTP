# 扫码与纯 OTP 账号

## 网页二维码

1. 在含二维码的网页上点击 LocalOTP 工具栏图标并解锁。
2. 点击右上角扫码图标 → 截取网页。原网页出现冻结画面的全屏蒙版，不创建新标签页。
3. 拖动框选二维码，保留四周留白，点击“识别选区”；也可识别整图。Esc 或取消退出。
4. 识别结果直接在原网页显示，可复制验证码或填写可选信息后“保存 OTP”。

工具栏弹窗、常驻小窗及置顶画中画均使用当前网页蒙版。常驻或置顶时，目标为最近使用的浏览器窗口中当前激活的标签页，排除插件小窗自身；不会在小窗中缩小展示整张网页。若目标页尚未获得本次截图授权，请先在该网页点击一次扩展工具栏图标。授权失败或目标为受保护页面时显示提示，不自动退回小窗内的来源选择器。

窗口选择依据本次浏览器会话中最近聚焦的窗口 ID，后台新开但未聚焦的标签页不会取代当前目标。该记录不含网址、标题或页面内容，浏览器重启后清除。

正式扩展使用 `activeTab` 临时授权和 `scripting` 注入能力，没有常驻站点权限。站点样式与扫码蒙版通过封闭 Shadow DOM 隔离，构造样式表兼容严格的页面 CSP。网页只得到这一次扫码的界面，不能访问已有账号库；消息绑定来源标签、顶层文档、随机令牌和已解锁页面凭证。锁定插件后会撤销该扫码会话。截图保留在页面内存中，后台会话区只保存本次扫码授权及临时 OTP，关闭、保存或 5 分钟超时后清除，不写入本地账号库或同步。

## 管理页与网页预览截图

管理页和 localhost 预览中的“截取网页”可直接点击。浏览器会弹出来源选择器，由用户选择网页、窗口或屏幕；得到一帧画面后立即停止共享，并在当前管理页蒙版中框选。取消可直接重试。此流程不自动选择其他网页，不需要新标签页，也不需要给扩展长期访问所有网站的权限。

工具栏直接扫码不能注入浏览器设置页、扩展商店等受保护页面；可改用管理页选择器或本地图片。较大的二维码先滚动到可见区域。所有图片与 QR 内容在本机处理。

## 图片与链接

- 本地图片支持 PNG、JPG、WebP、GIF、BMP，可选择文件、拖入或粘贴剪贴板中的图片。上限 10 MiB、2400 万像素。
- 支持 `otpauth://totp/...`、Base32 密钥，及含 `otp`、`secret`、`uri` 参数的 HTTP(S) 分享链接；只解析链接文字，不访问其网站。
- 图片网址、普通网页链接及 HOTP 不会被当作有效的 TOTP。图片网址请先保存为本地图片。多二维码截图请框选一个二维码。
- 保留原始 SHA-1 / SHA-256 / SHA-512、6 / 8 位及周期参数。损坏或不支持的内容显示明确错误。

## 只保存 OTP

新增表单仅 OTP 密钥必填，邮箱或账号名、密码、服务名称均可选。扫码结果无需补齐账号或密码即可保存。列表优先显示账号名或服务名，均为空时显示“未命名 OTP”；没有邮箱或密码时隐藏对应复制按钮。纯 OTP 记录的备份导入按密钥和 OTP 参数判重，多个空邮箱记录不会互相覆盖。

查看或复制验证码无需额外的一小时验证。查看、复制已保存账号密码及导出备份适用[密码验证规则](window-and-session.md#永久免密码与敏感操作)。
